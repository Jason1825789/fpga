# 频谱分箱：从线性改半对数（r41）

日期：2026-11-04
改动文件：`src/user_source/hdl_source/audio/spectrum_engine.v`
基线：r34（`58550247`）

---

## 一、为什么要改

原来的 `spectrum_engine` 用**线性分箱**：每根柱固定负责 6 个 bin。

```
FFT 1024 点 @ 48kHz  →  bin 宽 46.875 Hz
80 柱 × 6 bin = 480 bin = 0 ~ 22.5 kHz，每柱固定 281 Hz
```

问题在于**音乐能量集中在低频**。以板上现有的音阶（C4~C5，262~523Hz）为例：

| 频率 | bin | 落到的柱 |
|---|---|---|
| C4 261.6 Hz | 5.6 | 柱 0.77 |
| C5 523.3 Hz | 11.2 | 柱 1.79 |
| 3 次谐波 785 Hz | 16.7 | 柱 2.6 |
| 7 次谐波 1831 Hz | 39.1 | 柱 6.3 |

**一个八度的音阶只占柱 0~2，加上方波谐波也就到柱 6~13，右边 70 根柱永远是空的。**

人的听觉是**对数**的（八度等分），音乐的能量分布也是对数集中的。专业频谱仪一律用对数分箱（每柱负责固定音程而不是固定带宽）。这是本次改动的依据。

## 二、改成了什么

**半对数**：前 32 柱线性（每柱 1 个 bin，保住低频分辨率），后 48 柱对数（每柱约 1.06 倍频宽 ≈ 0.96 半音）。

- bin 1（46.9 Hz）→ 柱 0
- bin 480（22.5 kHz）→ 柱 79 右边界
- 每柱最少 1 个 bin，最多 26 个 bin

为什么不全用对数：FFT 只有 1024 点、分辨率 46.875 Hz，在 100 Hz 附近一根柱只该有 4 Hz 宽，物理上分辨不出来。用线性段把低频每柱 1 个 bin，避免「多根柱显示同一个值」的阶梯感。

### 改后的映射（Python 逐点校验过）

| 频率 | 音名 | 柱号 |
|---|---|---|
| 130.8 Hz | C3 | 1 |
| 261.6 Hz | C4 | 4 |
| 329.6 Hz | E4 | 6 |
| 523.3 Hz | C5 | 10 |
| 785 Hz | C4×3 | 15 |
| 1046 Hz | C6 | 21 |
| 1308 Hz | C4×5 | 26 |
| 1570 Hz | C5×3 | 32 |
| 1831 Hz | C4×7 | 35 |
| 2616 Hz | C5×5 | 41 |
| 3924 Hz | C4×15 | 48 |

同一个音阶循环从"占柱 0~2"变成"铺开柱 1~48"。

## 三、实现要点

1. 新增函数 `edge_lut(k)`，k=0..80，返回第 k 根柱的起始 bin。81 项 case，综合成 LUT 表。
2. **删掉 `sub_cnt[3:0]`**（原来每 6 个 bin 计一次数），改用 `bin_cnt` 与边界比较：
   ```verilog
   wire is_bar_first = (bin_cnt == edge_cur);              // 本柱第一个 bin
   wire is_bar_last  = ((bin_cnt + 1) >= edge_next);       // 本柱最后一个 bin
   ```
3. `bin_in_range` 从 `<= BIN_LAST` 改为 `< BIN_LAST`（左闭右开，与表的定义严格一致）。
4. `BIN_LAST` 从 `N_BARS * BIN_STRIDE` 改成显式常量 `480`，避免与废弃参数隐式耦合。
5. `BIN_STRIDE` 参数保留但标废（仅为兼容旧例化的参数名）。

### 三条必须守住的约束（改之前先读）

- **边界表必须严格递增**，否则 `is_bar_first` 会漏判，某些柱永远不提交 —— 表现是"柱子卡住不动"。
- **每根柱至少覆盖 1 个 bin**，否则该柱收不到任何数据。
- **`edge_lut(80)` 必须等于 `BIN_LAST`**，否则最后一根柱会多收/少收 bin。

表是 Python 生成的，生成时断言了「严格递增」和「每柱 ≥1 bin」。改柱数或频段范围必须重新生成并重新跑仿真。

## 六、上板要看什么

1. **柱子应该铺满整个宽度**，而不是挤在最左边 —— 这是本次改动唯一的判据
2. 左边 1/3（低频段）的柱子会比原来更"灵敏"，因为每柱 1 个 bin
3. 右边 2/3 的柱子仍会比较矮（音阶的谐波到 4kHz 就衰减完了），换成真实音乐后会填满
4. 其它一切不变：进度视图 `01-08`、转场、字幕、音量开关

**如果柱子在某个位置"卡住不动"，说明边界表有漏判**，回来重跑 `tb_spec_logbin.v`。
